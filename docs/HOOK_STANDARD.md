## A. 콜드 오프닝 (0~60초) — 화면 부품 4종

| 구간 | 내용 | 부품 (장면 필드) |
|---|---|---|
| 0~10초 | 가장 극적인 순간(절정) 재연 그림 + 날짜·장소 | `hook.hud` (숫자 아님 → `count: false`) |
| 10~40초 | **수치 누적** — 병력·손실·격파 수·기간을 한 문장에 하나씩 | `hook.hud[]` 좌측 상단 수치 카드 (숫자 0.9초 카운트업) + 화면 `troops`(병력 미니어처 대열) |
| 40~50초 | **통념 부정** — "누가 봐도 참패" → "정말 그랬을까?" | `hook.neg` (통념 단어 위 붉은 X, `xOn`으로 의문문에 맞춰 그음) |
| 50~60초 | **핵심 질문 카드** — 끝까지 보면 답이 나온다는 약속 | `hook.question` (화면 어둡게 + 종이 질감 카드, `\n` 줄바꿈) → 다음 장면 `titlecard` |

- 앵글 후보 3개(갈등형·숫자형·질문형)를 뽑아 **①→②→③ 순서로 모순을 쌓고**, 질문 카드는 질문형(③)으로 끝낸다
- 콜드 오프닝에서 던진 숫자·질문은 본편에서 반드시 회수 — 대본 머리말에 회수 위치 표시, 질문 카드는 회수 장면에서 **같은 문구로 한 번 더** 띄운다(`kicker: "■ 처음의 질문 ■"`)
- 숫자는 사료로 확인된 것만 (대본·화면·썸네일 동일)

### 장면 필드 형식 (`remotion/Hook.tsx`)
```json
"hook": {
  "hud": [{"big": "3,933명", "sub": "대전을 지킨 미군", "sub2": "제24사단 투입 병력", "on": "삼천구백삼십삼", "color": "#FFD400", "count": true}],
  "neg": {"text": "참패", "at": 0.2, "xOn": "그랬을까요"},
  "question": {"text": "사단장까지 잃은 이 패배는\n어떻게 대한민국을 살렸나", "at": 0.05, "kicker": "■ 오늘의 질문 ■"}
}
```
- `at`/`until`은 줄 번호(+줄 안 비율), `on`·`xOn`·`untilOn`은 대사 단어 — `timeline.py`가 장면 전체에 `on` 변환을 적용하므로 hook 안에서도 쓸 수 있다
- `hud`는 여러 개면 순서대로 교체, 붉은 수치(손실·기간)는 `color: "#FF3B3B"`
- 위치는 좌측 상단(left 64, top 64) 고정 — 같은 장면에 `callouts` `pos: "top"`을 같이 쓰지 말 것(겹침)

### 화면 `troops` (3D 아이소메트릭 병력 대열)
`{"type": "troops", "n": 32, "cols": 8, "side": "us|kr|nk|cn", "keep": 22, "keepAt": 0.35, "title": "...", "labels": [{"x", "y", "text", "at|on", "color": "red|blue|dark"}], "vs": {"n", "side", "cols"}, "march": true}`
- 병사 1명 = 일정 비율(예: 3,933명 → 32명)로 모식화, `keep`/`keepAt` 시점부터 나머지가 사라져 손실 비율을 보여 줌
- 그림 생성 비용 0원 (SVG)

## B. 썸네일 표준 v2 (`PAROHO_V2`, 한국어 A안)

- **고정 흑백 군인 얼굴 사진 전면 폐기** (매 편 같은 인상 → 기시감·CTR 저하)
- 에피소드 고유 메인 비주얼을 화면 전체(Full-Bleed)로: 결정적 전황 장면의 AI 재연 그림(`ai_images.thumb_bg`, 실사풍 영화 스틸) 또는 3D 지형
- 하단 다크 비네팅 위 **대형 2줄 압축 카피(줄당 6~9자)** — 실측 폭으로 x 1720(재생시간 배지 여백 200px) 안을 꽉 채움, 최대 340px
- Line 1 흰색 / Line 2 머스터드 옐로 `#FFD400`, Pretendard Black, 굵은 검정 외곽선
- 선택: 좌상단 붉은 날짜·장소 배지(`badge`), 타깃 링·화살표(`targets`·`arrows`), 카피 시안(`alt` → `_ko_A2`)
- 카피 프레임: **'열세를 뒤집은 통쾌한 역전·기습 승리'** — 패배한 전투라도 그 안의 역전 순간(예: EP29 "무적 전차를 / 장군이 부쉈다")을 잡는다
- 구현: `remotion/Thumbnail.tsx` `PAROHO_V2` 표에 한 줄 → `ParohoV2Thumb` (PAROHO_STD v5보다 우선). `thumb_bg`는 미리보기 때 없으면 자동 생성, 다시 그리려면 `mode=thumb`
