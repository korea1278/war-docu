# 썸네일 표준 v5 'TV 우선 · 질문과 감정' — 2026-11-26 사용자 지시 · war-docu·map-of-war 공통 · 다음 신규 편부터 (v4보다 우선)

> 사용자가 영상 「give me 9 minutes, I'll make your thumbnails 81% better」(9분 55초, 썸네일 컨설턴트가 수천 개를 리뷰하며 90% 똑같이 하게 되는 조언)을 주며
> "상세히 분석해서 썸네일도 이런 조건에 맞게 나오게" 지시. 영상의 조언 6가지를 모두 우리 썸네일 엔진·절차에 넣었다.
> v4(조회수 레퍼런스: 태그 박스 · 큰 글자 2줄 · `[빨강]` `{노랑}` 단어 강조 · `box2` · 말풍선)의 장점은 그대로 두고, **글자를 위로 올리고 주인공을 세운다.**

## 영상이 말한 6가지 → 우리가 바꾼 것

| # | 영상의 조언 | 왜 | 우리 썸네일에 넣은 것 |
|---|---|---|---|
| 1 | **TV에서 보이게 (50% 테스트)** | 미국은 TV가 모바일을 넘어 유튜브 1위 기기. TV 홈·추천 화면은 썸네일 **위쪽 절반만** 보여 주고 제목은 리모컨 '아래'를 눌러야 보임. 아래 절반을 가렸을 때 '무슨 영상인지·눌러 볼지'가 안 보이면 TV 시청자에겐 빈 그림 | `tv: true` → **태그 + 큰 글자 2줄을 위쪽(화면 높이 46% 안)** 으로. v4는 글자가 아래라 TV에서 통째로 사라졌음. 점검 시트에 'TV 보기' 칸 자동 생성 |
| 2 | **제목에 기대지 말고 썸네일이 혼자 궁금증을 만들 것** | 화면마다 썸네일은 커지고 제목 글씨는 작아짐 → 사람들은 썸네일만 훑고, 제목은 일부러 읽어야 읽음 | 썸네일 문구는 제목을 몰라도 **질문(무엇이 궁금한가)·감정(무엇을 느끼는가)** 을 만들어야 함. 항목에 `why: {q, e}`로 기록(렌더 안 함). '관련 있는 그림'만으로는 부족 — 질문·감정이 관련성을 이긴다 |
| 3 | **맨땅에서 시작하지 말 것 — 참고 10~15개, 여러 출처** | 클릭을 가장 크게 바꾸는 기술 = 참고 자료를 제대로 모으고 쓰는 것 | 편마다 `episodes/<ep>/thumb_plan.md` (아래 형식) — 5가지 출처에서 참고를 모으고 각각의 **작동 원리**를 한 줄로 |
| 4 | **군더더기 빼기** | 실제로 있는 것이라도, 썸네일에서 일하지 않는 것은 방해가 된다 (다이빙 선수 사진의 난간) | `note`·`bubble`·화살표는 **그것 자체가 질문이나 감정을 만들 때만**. 배경은 `bgPos`로 잘라 내고, 필요하면 `focus`로 주변을 어둡게 |
| 5 | **주인공을 한눈에** | 주인공이 가장 먼저 눈에 들어와야 함 (다이빙 선수 수영복 색 바꾸기 + 'OLYMPIAN' 라벨) | `focus` 스포트라이트(주인공 둘레만 원래 색, 나머지는 어둡고 흐리게) · `cut` 누끼(흰 테두리 빛으로 떼어 냄) · `label` 이름표 |
| 6 | **글자 시안을 여러 개 (A/B 테스트)** | 가장 적은 노력으로 성과를 올리는 방법. 글자를 넣을 때마다 5분만 더 써서 다른 문구를 만들 것 | `alts: [...]` 배열 → A2·A3·…를 한 번에 렌더 (줄 끝 `// ALTS:<ep> n=<개수>`). **시안 최소 4개(A+3)**. 유튜브 '테스트 및 비교'(최대 3개)에 올릴 3개를 점검 시트로 고른다 |

## 화면 구성 (1920×1080, `remotion/HitThumb.tsx` — 두 저장소 같은 파일)
1. **배경**: 대본 핵심 장면 사진·재연 그림 Full-Bleed (war-docu 흑백 · map-of-war 컬러, v4와 같음). **주인공(사람·배·전차)이 화면 가운데~아래 가운데에 오게** `bgPos` — 위쪽엔 글자가 온다
2. **위쪽 46% = 태그 + 큰 글자 2줄** (`tv: true`) — 태그(작게, 56px)가 첫 줄, 그 아래 line1·line2. 글자 크기는 가로를 채우되 46% 높이 상한(보통 150~170px). 위에서 아래로 어두운 그라데이션
   - `align`: left(기본) · center · right — 주인공 얼굴을 덮지 않는 쪽
   - 강조색 `[빨강]` `{노랑}`, `box2`(2줄째 빨간 박스)는 v4와 같음
3. **주인공**: `focus: {x, y, rx, ry, dim}` (픽셀) — 그 타원 안만 원래 색, 바깥은 밝기 0.55·채도 0.55. `cut: "ep/<ep>/thumbcut/<이름>.png"` — thumb 모드가 `pipeline/thumb_cut.py`로 **배경과 같은 크기** 누끼를 만들어 같은 자리에 겹치고 흰 테두리 빛을 준다
   - ⚠️ `cut`은 **주인공이 하나로 뚜렷한 사진**(인물 초상, 배 한 척, 전차 한 대)에만. 군중·전열 그림에 쓰면 사람마다 하얗게 번져 유령처럼 보인다(2026-11-26 칸나이 그림으로 시험해 확인) → 군중은 `focus`만
   - `label: {text, x, y, style}` — 주인공 옆 작은 이름표("포위된 로마군", "강뉴 대대"). **위쪽 절반 안**에 두면 TV에서도 보임. 글자 2줄과 겹치지 않게
4. **군더더기 없음**: 기본은 태그 + 2줄 + 주인공(+이름표) 세 덩어리. 재생시간 표시 없음
5. **영상 안 첫 장면과 이어지게**: 썸네일의 질문을 콜드 오프닝 질문 카드(`hook.question`)와 같은 뜻으로 — 누르고 들어왔을 때 바로 이어지게

## 문구 공식 (대본에서 · 숫자는 출처 있는 것만)
- **질문형**: [불리한 전제·숫자] / [의외의 결과] + "~한 이유" — "2배 가까운 로마군이 / 하루 만에 갇힌 이유" → 질문: 어떻게? · 감정: 의아함
- **단정 반전형**: [전략] / [충격적 결과] + box2 — "일부러 밀려 주고 / 통째로 포위했다" → 질문: 왜 일부러? · 감정: 통쾌함
- **인물·감정형**: [인물] / [극한 상황] — "열아홉 살 선생님이 / 적 연대를 무너뜨렸다" → 감정: 놀라움·뭉클함
- **숫자 대비형**: [큰 숫자] vs [작은 숫자] — "87 대 6으로 끝난 / 새벽 길목" → 질문: 어떻게 그 차이가?
- **미스터리형**: [이상한 사실] + "~의 비밀" — "주인이 19번 바뀐 / 바위산의 비밀"
- 한 편에서 시안은 **서로 다른 공식**으로 (같은 말만 바꾸지 말 것). 줄당 5~10자, 한 줄 강조 1~2곳

## 편마다 `episodes/<ep>/thumb_plan.md` (대본 확정 직후, 썸네일 등록 전)
```
# <ep> 썸네일 기획
## 목표
- 질문: 시청자가 썸네일만 보고 궁금해할 것 (1~2개)
- 감정: 느끼게 할 것 (예: 통쾌함 · 비장함 · 의아함 · 분노)
## 참고 (10~15개 · 5가지 출처에서 섞어서)
| 출처 | 참고 | 만드는 질문 | 만드는 감정 | 작동 원리(어떻게) |
|---|---|---|---|---|
| 우리 채널 잘된 편 | 격전의 지도 EP13 파로호 | … | … | … |
| 남의 잘된 영상 | (같은 주제·평균보다 조회수 높은 것) | | | |
| 형식이 같은 다른 분야 채널 | (지도·역사 설명, 다른 주제) | | | |
| 저장해 둔 썸네일 | docs/THUMB_REFERENCES.md | | | |
| 유튜브 밖 | 영화 포스터·신문 1면·광고 | | | |
## 시안 (최소 4개 · 서로 다른 공식)
- A: … (질문 … / 감정 …)
- A2: …
## 점검 (thumbnails/<ep>_check.jpg)
- [ ] TV 보기(위 절반)만으로 무슨 영상인지·궁금한지 보인다
- [ ] 휴대폰 추천 목록 크기(168px)에서 글자가 읽히고 주인공이 먼저 보인다
- [ ] 일하지 않는 요소가 없다 (라벨·화살표·말풍선 각각 '왜 있는지' 설명 가능)
- [ ] 숫자는 research.md 출처가 있다
- [ ] 유튜브 '테스트 및 비교'에 올릴 3개 선택: …
```
- 참고 모으기: 우리 채널·남의 영상의 '평균보다 잘된 영상'은 사용자가 유튜브 스튜디오·검색에서 보내 주는 캡처나 목록을 받는다 (세션에서 유튜브 분석 화면은 못 봄). 사용자가 '이런 썸네일 좋다'며 가져온 것은 전부 `docs/THUMB_REFERENCES.md`에 작동 원리와 함께 쌓아 다음 편부터 재사용
- **참고는 베끼지 않는다** — 작동 원리만 가져와 우리 소재에 옮긴다 (2026-11-24 사용자 지시와 같음)

## 등록 예 (PAROHO_V2)
```ts
"ep35-xxx": {
  bg: "ep/ep35-xxx/photos/s061_photo_0.jpg", bgPos: "50% 70%",
  tv: true, tag: "낙동강 | 1950.8", tagStyle: "red",
  line1: "트럭 [300대]가", line2: "{30대만} 남은 이유",
  focus: { x: 1150, y: 640, rx: 620, ry: 300 }, label: { text: "제24사단 수송대", x: 1180, y: 470, style: "yellow" },
  why: { q: "270대는 어디로?", e: "충격·안타까움" },
  alts: [
    { tag: "그날 새벽", tagStyle: "black", line1: "다리 하나 [잘못] 끊어", line2: "부대가 갇혔다", box2: true },
    { line1: "1950년 8월", line2: "트럭이 사라진 길", tagStyle: "cream" },
    { line1: "{300대} → [30대]", line2: "닷새 동안 생긴 일" },
  ],
}, // ALTS:ep35-xxx n=3
```
- `alts` 각 항목은 본안을 덮어쓴다 (bg·focus·cut도 바꿀 수 있고, `focus: undefined`로 끌 수 있음)
- Actions `mode=thumb` → `thumb_cut.py`(cut이 있을 때) → A·A2…·en_A 렌더 → **`thumbnails/<ep>_check.jpg`**(원본 · TV 50% 테스트 · 휴대폰 홈 · 추천 목록) 자동 생성·커밋
- 세션에서: 번들 → `npx remotion still … Thumbnail thumbnails/<ep>_ko_A3.png --props='{"ep":"<ep>","variant":"A3","lang":"ko"}'` → `python3 pipeline/thumb_check.py <ep>` → 점검 시트를 직접 열어 확인
- `tv`가 없는 예전 항목은 v4 그대로 렌더된다 (기존 편 영향 없음)
