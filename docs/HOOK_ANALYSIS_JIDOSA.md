## 2. 대본 구조 (EP29 적용 예)
1. 절정: "1950년 7월 20일 대전. 불타는 시가지 한복판에서 한 장군이 적 전차를 쫓고 있었습니다."
2. 수치 누적: 3,933명 → 1,150명(이틀) → 전차 10대 격파 → 그런데도 하루 만에 함락 → 36일 실종
3. 통념 부정: "누가 봐도 참패였죠. 그런데 정말 그랬을까요."
4. 권위 있는 반전 근거: 미 육군 공식 전사 "귀중한 시간을 벌었다"
5. 핵심 질문: "사단장까지 잃은 이 패배는 어떻게 대한민국을 살렸을까요."
6. 시간 순 본편으로 이어 주는 한 문장 → 타이틀 카드
