## 2. 레퍼런스가 시청자를 붙잡는 장치 (우리에게 없던 것)

1. **늘 보이는 '언제·어디'** — 왼쪽 위 명조 날짜 `1968. 1. 21` + 빨간 시각 칩 `21:40`·`밤`, 오른쪽 위 종이 범례(세력 기호·길·축척·지도 출처). 이야기가 시간 순으로 흐르는 걸 화면이 계속 알려 줌
2. **시간대로 바뀌는 지도 색** — 낮 = 미색 종이 지형, 밤 = 짙은 청색 지형. 설명 없이도 "지금은 밤"을 느낌
3. **지도 위에 얹는 정보** — 큰 숫자 카드(`45km`·`49시간`·`250m`)는 지도 왼쪽에, 신문 기사 인용(`동아일보 1968. 1. 22 3면` + 노란 형광펜)도 지도 위 종이 카드로. 빈 배경 카드로 넘어가지 않음
4. **사료 원문 + 번역** — 영어 원문 사료를 작게 보여 주고 핵심어에 형광펜, 아래에 한국어 번역을 크게
5. **사진·재연 그림 하단 제목** — 노란 날짜 칩 + 큰 명조 제목 + 회색 한 줄 설명, 오른쪽 아래 작은 출처
6. **카운트다운·소거** — "남은 길 4 → 3 → 2 → 1", 선택지를 하나씩 X로 지움 (우리 reasons와 같은 원리지만 **지도 위에서** 함)
7. **장 제목이 시간** — 1장 '사흘' / 2장 '49시간' / 3장 '네 시간'. 이야기 속도가 점점 빨라진다는 걸 장 제목이 알려 줌
8. **도입 50초** — 결과(1명만 생포) → 거리(45km)·기간(나흘) → 모순(49시간 전에 신고됐는데 이틀을 찾고도 청와대 앞까지) → 반전(숨어서가 아니라 두 줄로 큰길을 걸어서) → 핵심 질문("어떻게 청와대 앞까지 왔을까요?") → 본편. 타이틀 카드·효과음 없이 지도로만
9. **끝맺음** — 현재(2026. 10. 17) 현장 사진과 생존자 근황으로 여운, 구독 요청은 지도 위 종이 카드 한 장으로 조용히

## 4. 대본·연출 규칙 (다음 편부터)
1. **지도 60% 이상, 글자 카드 25% 이하.** 숫자·이유·인용은 지도 장면 위에 콜아웃·`clip`·`hook.hud`로 얹는다. text·black 카드는 장 전환·핵심 반전 1~2번만
2. **같은 지도 이어 쓰기** — 연속 장면은 같은 `views` 키 근처로 카메라만 옮기고 아이템을 하나씩 더한다 (지도 → 사진 → 지도 → 카드 식으로 매번 갈아엎지 않기)
3. **시간 표시** — 첫 지도 장면에 `date`·`legend`, 날짜·시각이 바뀌는 문장에서만 다시 지정. 밤 장면은 `visual.tone: "night"`
4. **장 제목을 시간·숫자로** (예: '45일', '마지막 사흘', '열아홉 번')
5. **재연 그림은 실사풍 시네마틱 재연이 기본** — 프롬프트 예: "cinematic photorealistic reenactment, 1950 Korean War, muted desaturated film color, soldiers seen from behind or at distance, faces not identifiable, dusk haze, 35mm documentary still, no text, no flags with readable symbols". 국기 볼 캐릭터는 `stage`(종이 무대) 장면에만. (사용자가 볼 캐릭터를 유지하라고 하면 이 줄은 무시)
