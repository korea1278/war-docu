# war-docu 롱폼 영구 제작 표준 규칙 (다음 에피소드부터 필수 적용)

> 2026-11-13 사용자 지시서로 제정. EP26 승호리 철교(`ep26-seungho`)는 2번(효과음 제거·BGM -24dB)만 소급 적용해 재렌더링했고, 나머지는 EP27부터 모든 롱폼에 적용한다.

1. 오디오 막(Act) 단위 통파일 생성 원칙 (Strict Act-by-Act Single MP3)
   - 문장이나 자막 줄 단위로 쪼개서 ElevenLabs API를 호출하는 행위 전면 금지 (끝음 단절 및 디지털 팝 노이즈 원천 차단).
   - 반드시 **1개 막(Act) 전체 텍스트를 1회의 API 호출로 단일 통파일(`act1.mp3` ~ `act7.mp3`)**로 추출하여 문단 단위의 자연스러운 호흡과 억양을 유지할 것.
   - 대본 정제 규칙: 괄호 지문(`(비장하게)` 등) 전면 금지, 불필요한 쉼표(,) 제거, 100% 한글 발음 표기 및 어색한 띄어쓰기(예: "천구백오십이 년" ➔ "천구백오십이년") 교정으로 TTS 끝음 왜곡 방지.

2. 절제된 다큐멘터리 SFX 믹싱 기준 (2026-11-13 사용자 수정 지시 — 이전 '효과음 전면 금지'를 대체. 전면 삭제는 영상이 지나치게 건조해짐)
   1) 절대 금지할 효과음 (Ban)
      - **갑작스럽고 과장된 저음 폭발/타격음('꽝' 하는 Loud Boom, Heavy Slam SFX) 금지.**
      - 캐릭터(컨트리볼), 말풍선, 텍스트 박스, 체크리스트가 뜰 때마다 반복 재생되는 **가벼운 UI `Pop` 효과음 전면 금지.**
      - 동일 효과음이 15초 이내에 연속으로 중복 재생되는 현상 금지 (쿨다운 최소 15초 이상 적용).
   2) 적절히 살려서 배치할 효과음 (Allow & Mix)
      - **전술 지도 및 장면 전환:** 막(Act)이 바뀌거나 3D 카메라가 주요 고지·전장으로 크게 이동(Flythrough)할 때만 차분하고 묵직한 저음 스윕(Subtle Cinematic Whoosh/Sweep)을 절제하여 1회 사용.
      - **전장 현장감 앰비언스(Ambience):** 대규모 포격전, 돌파전, 고지 사투 등 클라이맥스 장면에 한해 나레이션을 방해하지 않는 선에서 은은한 배경 현장음(먼 포성 울림, 바람 소리, 무전 교신 노이즈 등)을 아주 낮게(`-28dB ~ -32dB`) 깔아 몰입감 부여.
      - **전술 HUD 포인트:** 적 포위망이 완성되거나 핵심 타깃 록온 링이 활성화될 때만 절제된 레이더 비프(Radar Ping) 효과음 1회 허용.
   3) 전체 오디오 밸런스 기준
      - 메인 성우 나레이션: `0dB` (기준)
      - 다큐멘터리 BGM: `-22dB ~ -26dB`
      - 절제된 포인트 SFX / 현장 앰비언스: `-24dB ~ -32dB` (절대 나레이션 목소리를 덮거나 놀라게 하지 않는 수준)

3. 자막 싱크 정렬 규칙
   - 통으로 추출된 `act1.mp3` ~ `act7.mp3`의 실제 음파 파형에 맞춰 자막 JSON 타임스탬프를 동기화할 것 (오차 ±0.5초 이내).
   - 자막은 한 줄당 25~35자 내외의 자연스러운 문장 결합형 유지.

4. 렌더링 및 영상 연출 원칙
   - 시간 함수(`Date.now()`, `setTimeout`) 사용 금지, 철저히 `frame / 30` 기반 결정론적 프레임 제어(Deterministic Rendering) 엄수.
   - `MapView.tsx` 3D 지형 비행(`CatmullRomCurve3`), SVG 스트로크 진격선 및 파티클 스웜, Tactical HUD 오버레이 표준 유지.

## 이 저장소에서 지키는 방법 (구현 메모)

| 규칙 | 스토리보드·엔진 설정 |
|---|---|
| 1. 막 단위 통파일 TTS | 스토리보드 최상단 `"tts_mode": "act"` (`pipeline/tts.py` 막 단위 모드 — EN-08 장진호 때 추가). 막 경계는 `chapter`가 달린 장면 기준. 대본 숫자 발음은 "천구백오십이년"처럼 붙여 쓴다 |
| 2. 절제된 다큐 SFX | 스토리보드 최상단 `"sfx_policy": "doc"` → `timeline.py` `doc_sfx()`가 자동 처리: 금지 목록(`boom`·`hit`·`artillery`(근거리)·`mg`·`drum`·`pop`) 삭제, 콜아웃 자동 pop 없음, **막 전환(`chapter`)마다 `whoosh` 스윕 1회 자동**, 같은 효과음 15초 쿨다운, 볼륨은 나레이션 대비 dB로 계산(`whoosh`·`ping` -26 / `artillery_far`·`wind`·`tank` -30 / `water`·`birds` -32, 장면 cue에 `"db"`로 -24~-32 안에서 조정). 효과음별 LUFS는 `public/sfx/loudness.json`(새 효과음을 넣으면 측정해 추가). 장면에 넣을 것: 3D 비행(`flight`) 장면 `whoosh`, 클라이맥스 포격 장면 `artillery_far`(먼 포성), 겨울·고지 장면 `wind`, 핵심 록온(`lock`) 장면 `ping`(레이더 비프 — 2026-11-13 ffmpeg로 직접 합성, API 비용 0). `"sfx": false`는 효과음 전부 끄기(예비 옵션) |
| 2. BGM -22~-26dB | 스토리보드 최상단 `"bgm_rel_db": -24` → `timeline.py`가 나레이션 통합 음량(ffmpeg ebur128 샘플 측정)과 `public/bgm/loudness.json`(공용 6곡 LUFS)으로 곡마다 볼륨을 계산. 새 BGM 파일을 넣으면 loudness.json에 LUFS 추가 |
| 3. 자막 ±0.5초 · 25~35자 | 싱크 검사 `pipeline/check_sync.py` 허용 오차를 ±0.5초로, `timeline.py` `split_phrase` 한 줄 최대 글자 수를 35자 안팎으로 조정 (EP27 작업 때 먼저 반영 · 64px 자막 박스 폭 안에 들어가는지 미리보기로 확인) |
| 4. 결정론 렌더 | Remotion `useCurrentFrame()`/fps 기반만 사용 — 새 컴포넌트에서도 `Date.now()`·`setTimeout`·`Math.random()` 금지 (난수는 hash 결정론) |

- 적용 기록: EP26 `ep26-seungho` — `"sfx_policy": "doc"`, `"bgm_rel_db": -24` (나레이션 -17.9 LUFS 기준, BGM 볼륨 0.03~0.07). 기존 효과음 큐 28개(꽝·심장박동·hit 등) 삭제 → 막 전환 스윕 6·비행 스윕·먼 포성·바람·레이더 핑 4 등 28개 배치(쿨다운·금지로 14개 제외), TTS 재호출 없이 기존 `public/ep/ep26-seungho/tts` 재사용해 재렌더링 (2026-11-13)
